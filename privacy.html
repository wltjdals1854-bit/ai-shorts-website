AI Shorts Autopilot 개인정보처리방침

최종 업데이트: 2026년 10월 21일

AI Shorts Autopilot은 개인 유튜브 채널의 영상 제작, 비공개 업로드 및 성과 확인을 돕는 도구입니다. 아래 내용은 현재 프로그램 구성에 기반한 설명입니다.

1. 이용하는 정보

사용자의 Google OAuth 동의를 받아 YouTube 영상 업로드 권한과 계정·동영상 조회 권한을 사용합니다. 업로드된 동영상의 ID, 제목 및 조회수·좋아요·댓글 수 등 통계 정보도 처리할 수 있습니다.

2. 이용 목적

연결된 사용자의 YouTube 채널에 영상을 비공개로 업로드하고 업로드 결과를 확인하며 동영상의 공개 통계를 수집하기 위해 이용합니다. 제3자의 광고 타기팅이나 개인정보 판매를 목적으로 사용하지 않습니다.

3. 보관 및 처리 위치

OAuth 인증 토큰과 클라이언트 인증 정보는 운영자가 관리하는 GitHub Actions Secrets에 보관되어 자동화 실행 시 사용됩니다. 영상 ID와 성과 통계, 제작 상태 등의 기록은 운영자의 비공개 GitHub 저장소에서 관리됩니다. 생성된 영상과 대본은 작업 확인용 산출물로 일시적으로 보관될 수 있습니다.

4. 외부 서비스

이 도구는 Google/YouTube API, GitHub Actions 및 영상·대본 생성 서비스(OpenAI API 등)를 이용합니다. 각 서비스는 자체 개인정보처리방침을 적용할 수 있습니다.

5. 정보 보관 및 삭제

계정 연결 해제 또는 데이터 삭제는 운영자의 설정 및 저장소 관리로 처리됩니다. 사용자는 Google 계정의 서드파티 액세스 관리에서 앱의 접근 권한을 철회할 수 있습니다. 접근 권한 철회는 이미 업로드된 영상이나 별도로 저장된 기록을 자동으로 삭제하지 않을 수 있습니다.

6. 문의

현재 개인용 도구로 별도의 공개 고객지원 창구는 제공하지 않습니다. 운영자는 Google OAuth 동의 화면에 표시된 개발자 연락처를 통해 문의를 받을 수 있습니다.

7. 변경

데이터 처리 방식이 변경되면 이 페이지를 업데이트합니다.
